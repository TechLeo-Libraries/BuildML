# process-tda-shape

You have manufacturing sensor clouds (temperature, pressure, vibration, flow,
torque) labeled in-spec vs drifted. You want topological descriptors, not
the credit-risk TDA table in `credit-tda-shape`.

## Data

Synthetic / in-script license-clear in-spec vs drifted process clouds
generated by `script.py`.

## Leakage

Stratified train / validation / test before any fit. Scale, TDA vectorizer,
and head fit on train only. Holdout `session.tda.evaluate` runs after lock.
Test is never used for selection.

## How to run

```bash
python proofs/process-tda-shape/script.py
python proofs/process-tda-shape/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / macro_f1. `results/comparison.json`
is classical logistic on scaled raw process features (no TDA) on the same
stratified split.

## Limitations

Synthetic sensor clouds; TDA features are shape descriptors, not plant SPC.
Requires `ripser` + `persim`. Skips honestly with `skipped_missing_extra`
when extras are unavailable.
