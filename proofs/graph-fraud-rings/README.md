# graph-fraud-rings

You have a transaction/entity graph and node labels. You want to classify
nodes to surface fraud rings, with classical graph features as the primary
path.

## Data

Synthetic / in-script license-clear graph generated by `script.py`.

## Leakage

Node split before `session.graph.fit`. Classical features come from the
train-visible graph. Test `session.graph.evaluate` runs after lock. An
optional torch GCN probe runs only when torch is healthy.

## How to run

```bash
python proofs/graph-fraud-rings/script.py
python proofs/graph-fraud-rings/baseline_industry.py
```

## What you'll get

`results/results.json` with node classification metrics.
`results/comparison.json` is networkx degree/clustering on the train+val
visible graph plus a logistic classifier.

## Limitations

Classical NetworkX path is primary; torch/PyG is optional.
