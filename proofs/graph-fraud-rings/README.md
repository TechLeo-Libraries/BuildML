# graph-fraud-rings

## Business purpose
Classify nodes in a transaction/entity graph to surface fraud rings.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. session.graph.set_spec / ingest node table → session.graph.fit(classical)
2. session.graph.evaluate
3. optional torch GCN if torch healthy
4. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` builds networkx degree/clustering on the train∪val visible graph + logistic classifier (`results/comparison.json`).
## Limitations
Classical NetworkX path primary; torch/PyG optional.
