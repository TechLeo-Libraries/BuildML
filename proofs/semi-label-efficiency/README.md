# semi-label-efficiency

## Business purpose
Train a classifier when only a scarce fraction of train labels are available.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → scale
2. mask most train labels
3. fit_semisupervised → evaluate_semisupervised
4. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Filled: `baseline_industry.py` runs sklearn `LabelPropagation` with the same train-only masking policy (`results/comparison.json`).
## Limitations
Synthetic 2-blob data; oracle masking is proof-only.
