# semi-label-efficiency

You have a table where only a scarce fraction of train labels are available.
You want a semi-supervised classifier evaluated on fully labeled holdouts.

## Data

Synthetic / in-script license-clear 2-blob table generated by `script.py`.

## Leakage

Split before masking or fit. Most train labels are masked; holdouts keep
full labels for evaluation only. `session.semisupervised.fit` runs on train.
Test `session.semisupervised.evaluate` runs after lock.

## How to run

```bash
python proofs/semi-label-efficiency/script.py
python proofs/semi-label-efficiency/baseline_industry.py
```

## What you'll get

`results/results.json` with holdout classification metrics.
`results/comparison.json` is sklearn `LabelPropagation` with the same
train-only masking policy.

## Limitations

Synthetic 2-blob data; oracle masking is for the proof only.
