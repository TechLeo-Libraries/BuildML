# tabular-ssl-probe

You have IoT sensor features and a fault label. You want a masked-tabular
SSL representation, then a probe. This DGP is distinct from
`ssl-representation-probe`.

## Data

Synthetic / in-script license-clear sensor table generated by `script.py`.

## Leakage

Stratified split before pretext. Pretext and probe fit on train only. Test
evaluation after lock.

## How to run

```bash
python proofs/tabular-ssl-probe/script.py
python proofs/tabular-ssl-probe/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / f1 / roc_auc.
`results/comparison.json` is a PCA embedding plus logistic probe on the
same split.

## Limitations

Tabular masked pretext only; not vision SSL.
