# tabular-ssl-probe

## Business purpose

Learn a masked-tabular SSL representation on IoT sensor features, then probe
for fault classification — distinct DGP from `ssl-representation-probe`.

## Data source

Synthetic / in-script license-clear sensor table generated by `script.py`.

## Leakage controls

- Stratified split before pretext
- Pretext + probe fit on train only
- Test evaluation after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. `fit_ssl_pretext` (masked_tabular)
3. Optional `finetune_ssl_head`
4. `evaluate_ssl` → `save_ssl_bundle`

## Metrics

See `results/results.json` (accuracy / f1 / roc_auc).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` uses PCA embedding + logistic probe
(`results/comparison.json`).

## Limitations

Tabular masked pretext only; not vision SSL.
