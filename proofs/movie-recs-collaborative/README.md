# movie-recs-collaborative

You have user-item interactions for a streaming storefront. You want catalog
recommendations from train interactions only, then holdout hit-rate / nDCG.

## Data

Synthetic / in-script license-clear interactions generated by `script.py`.

## Leakage

Split before recommender fit. `session.recommender.fit` learns from train
only. Test `session.recommender.recommend` / `session.recommender.evaluate`
run after lock.

## How to run

```bash
python proofs/movie-recs-collaborative/script.py
python proofs/movie-recs-collaborative/baseline_industry.py
```

## What you'll get

`results/results.json` with holdout recommender metrics (hit-rate / nDCG).
`results/comparison.json` is item-cosine similarity plus a popularity
cold-start, fit on train interactions only. ALS runs when `implicit` is
installed, else item_knn.

## Limitations

Synthetic interactions; ALS via `implicit` when installed, else item_knn.
