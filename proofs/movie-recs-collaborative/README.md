# movie-recs-collaborative

## Business purpose
Recommend catalog items from user–item interactions for a streaming storefront.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → roles → split
2. session.recommender.fit (ALS if implicit installed else item_knn)
3. `session.recommender.recommend` / `session.recommender.evaluate`
4. session.recommender.save_bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` builds item-cosine similarity (+ popularity cold-start) on train interactions only (`results/comparison.json`).
## Limitations
Synthetic interactions; ALS via `implicit` when installed, else item_knn.
