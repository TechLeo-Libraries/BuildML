# sku-embedding-clusters

## Business purpose

Cluster product embedding vectors into merchandising families and validate
against held-out synthetic family labels — distinct from RFM customer
segmentation.

## Data source

Synthetic / in-script license-clear SKU embedding table generated by
`script.py`.

## Leakage controls

- Scale + PCA fit on train only
- Clusters fit on train
- External family labels used only for evaluation (`role=ignore`)
- Test metrics after model lock

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale` → `reduce_dimensions`
2. `fit_clusters` (kmeans)
3. `evaluate_clusters` on validation / test with external labels
4. `save_unsupervised_bundle`

## Metrics

See `results/results.json` (silhouette / ARI / NMI).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` runs sklearn KMeans + PCA
(`results/comparison.json`).

## Limitations

External labels exist only because data is synthetic.
