# sku-embedding-clusters

You have product embedding vectors and want merchandising families. This is
distinct from RFM customer segmentation in `cluster-customer-segments`.
Synthetic family labels exist only for holdout evaluation.

## Data

Synthetic / in-script license-clear SKU embedding table generated by
`script.py`.

## Leakage

Scale and PCA learn from train only. Clusters fit on train. External family
labels are evaluation-only (`role=ignore`). Test metrics run after the model
is locked.

## How to run

```bash
python proofs/sku-embedding-clusters/script.py
python proofs/sku-embedding-clusters/baseline_industry.py
```

## What you'll get

`results/results.json` with silhouette / ARI / NMI.
`results/comparison.json` is sklearn KMeans + PCA on the same split.

## Limitations

External labels exist only because the table is synthetic.
