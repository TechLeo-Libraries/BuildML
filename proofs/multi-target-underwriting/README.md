# multi-target-underwriting

## Business purpose
Predict multiple same-type underwriting outcomes (e.g. approve + high-limit flags).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest multi-target table → split
2. fit_multitask → evaluate_multitask
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled — `baseline_industry.py` writes `results/comparison.json` (sklearn MultiOutputClassifier + LogisticRegression on the same split).


## Limitations
Synthetic multi-label targets.
