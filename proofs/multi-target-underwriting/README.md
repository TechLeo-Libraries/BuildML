# multi-target-underwriting

You have one feature table and several same-type underwriting outcomes (for
example approve plus a high-limit flag). You want a multi-output fit and
holdout metrics across targets.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before `session.multitask.fit`. Train-only fitting. Holdout
`session.multitask.evaluate` after lock. Test is never used for selection.

## How to run

```bash
python proofs/multi-target-underwriting/script.py
python proofs/multi-target-underwriting/baseline_industry.py
```

## What you'll get

`results/results.json` with per-target and mean classification metrics.
`results/comparison.json` is sklearn `MultiOutputClassifier` +
`LogisticRegression` on the same split.

## Limitations

Synthetic multi-label targets.
