# kg-biomed-linkpred

## Business purpose
Predict missing biomedical-style knowledge-graph links (gene–disease–drug motifs).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest triples → roles → split
2. fit_kg(TransE)
3. predict_links / evaluate_kg
4. save_kg_bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled: `baseline_industry.py` writes `results/comparison.json` (train co-occurrence PMI / filtered ranking twin on the same triple split).


## Limitations
Synthetic KG; not PubMed/UMLS licensed data.
