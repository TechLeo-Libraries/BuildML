# kg-biomed-linkpred

You have biomedical-style triples (gene-disease-drug motifs). You want
missing-link prediction with TransE embeddings and filtered ranking on a
held-out triple split.

## Data

Synthetic / in-script license-clear triples generated by `script.py`.

## Leakage

Triple split before fit. `session.kg.fit` (TransE) learns from train only.
Test `session.kg.predict_links` / `session.kg.evaluate` run after lock.

## How to run

```bash
python proofs/kg-biomed-linkpred/script.py
python proofs/kg-biomed-linkpred/baseline_industry.py
```

## What you'll get

`results/results.json` with hits@k, mean rank, and MRR.
`results/comparison.json` is train co-occurrence PMI / filtered ranking on
the same triple split.

## Limitations

Synthetic KG; not PubMed/UMLS licensed data.
