# few-shot-domain-adapt

You have episodic tasks and a few labeled support examples on a new domain.
You want meta-learning adaptation, then episodic holdout metrics on tasks
the support set never mixed with test.

## Data

Synthetic / in-script license-clear episodic table generated by `script.py`.

## Leakage

Group / episodic split before `session.metalearning.fit`. Adaptation and
evaluation use held-out tasks only. Test is never used for selection.

## How to run

```bash
python proofs/few-shot-domain-adapt/script.py
python proofs/few-shot-domain-adapt/baseline_industry.py
```

## What you'll get

`results/results.json` with episodic accuracy / f1.
`results/comparison.json` is a per-task NearestCentroid k-shot twin on the
same `group_split`. Torch paths skip when unavailable.

## Limitations

Synthetic episodes; torch/industry paths skipped if unavailable.
