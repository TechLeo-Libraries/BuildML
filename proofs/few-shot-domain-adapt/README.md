# few-shot-domain-adapt

## Business purpose
Adapt to a new domain/task with few labeled support examples (episodic meta-learning).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest episodic table → session.metalearning.fit
2. session.metalearning.adapt / session.metalearning.evaluate
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Industry twin: `baseline_industry.py` writes `results/comparison.json` (per-task NearestCentroid k-shot twin on the same group_split).


## Limitations
Synthetic episodes; torch/industry paths skipped if unavailable.
