# warranty-cbr-memory

## Business purpose

Approve or deny warranty claims by retrieving similar historical cases
(case-based reasoning): distinct from insurance claims memory proofs.

## Data source

Synthetic / in-script license-clear warranty claim feature table generated by
`script.py`.

## Leakage controls

- Stratified split before CBR fit
- Case memory built from train only
- Test retrieval / evaluation after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. `session.cbr.fit` → `session.cbr.retrieve`
3. `session.cbr.evaluate` on test
4. `session.cbr.save_bundle`

## Metrics

See `results/results.json` (accuracy and retrieval metadata).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` uses sklearn `KNeighborsClassifier`
(`results/comparison.json`).

## Limitations

CBR ≠ RAG; synthetic warranty claims only.
