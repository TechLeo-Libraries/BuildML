# campaign-budget-optimize

You have marketing lead features and a response label. You want a
cost-sensitive threshold and a knapsack outreach set under a contact budget,
selected on validation.

## Data

Synthetic / in-script license-clear lead feature table generated by
`script.py`.

## Leakage

Stratified split; classifier fit on train. Decision policies selected on
validation only. Test `session.decision.evaluate` / `session.decision.apply`
after lock.

## How to run

```bash
python proofs/campaign-budget-optimize/script.py
python proofs/campaign-budget-optimize/baseline_industry.py
```

## What you'll get

`results/results.json` with threshold test metrics and knapsack selection.
`results/comparison.json` is a validation cost-threshold sweep.

## Limitations

Not general OR; disclosed knapsack/threshold helpers only.
