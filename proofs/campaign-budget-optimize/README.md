# campaign-budget-optimize

## Business purpose

Score marketing leads for campaign response, then select a cost-sensitive
threshold and knapsack outreach set under a contact budget.

## Data source

Synthetic / in-script license-clear lead feature table generated by `script.py`.

## Leakage controls

- Stratified split; classifier fit on train
- Decision policies selected on validation only
- Test `session.decision.evaluate` / `session.decision.apply` after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `fit` (logistic)
2. `session.decision.fit` (threshold on validation)
3. `session.decision.fit` (knapsack on validation)
4. `session.decision.evaluate` / `session.decision.apply` on test → bundle

## Metrics

See `results/results.json` (threshold test metrics + knapsack selection).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` runs a validation cost-threshold sweep
(`results/comparison.json`).

## Limitations

Not general OR; disclosed knapsack/threshold helpers only.
