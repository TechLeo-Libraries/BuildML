# edge-fleet-federated

You have non-IID edge devices and a fault label. You want FedAvg across
telemetry clients: distinct from the hospital-silo table in
`federated-hospital-sim`.

## Data

Synthetic / in-script license-clear edge telemetry table generated by
`script.py`.

## Leakage

`group_split` by `device_id`. Federated fit on train clients only. Holdout
devices/rows are reserved for evaluation.

## How to run

```bash
python proofs/edge-fleet-federated/script.py
python proofs/edge-fleet-federated/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / f1. `results/comparison.json` is
pooled centralized SGD on the same split.

## Limitations

Local FedAvg simulation only: not a deployed FL network.
