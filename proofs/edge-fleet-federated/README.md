# edge-fleet-federated

## Business purpose

Simulate FedAvg fault classification across non-IID edge devices (telemetry
clients) — distinct from the hospital-silo narrative in
`federated-hospital-sim`.

## Data source

Synthetic / in-script license-clear edge telemetry table generated by
`script.py`.

## Leakage controls

- `group_split` by `device_id`
- Federated fit on train clients only
- Holdout devices/rows for evaluation

## BuildML API steps

1. `ingest` → `set_roles` → `group_split`
2. `fit_federated` (fedavg)
3. `evaluate_federated` on test
4. `save_federated_bundle`

## Metrics

See `results/results.json` (accuracy / f1).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` runs pooled centralized SGD
(`results/comparison.json`).

## Limitations

Local FedAvg simulation only — not a deployed FL network.
