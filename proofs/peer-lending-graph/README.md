# peer-lending-graph

You have a P2P borrower graph and collusive-default labels. You want
graph-aware classical features: distinct from card/payment rings in
`graph-fraud-rings`.

## Data

Synthetic / in-script license-clear borrower graph generated by `script.py`.

## Leakage

Node stratified split before fit. Classical graph features come from the
train-visible graph view. Test evaluation after lock.

## How to run

```bash
python proofs/peer-lending-graph/script.py
python proofs/peer-lending-graph/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / f1 / roc_auc.
`results/comparison.json` is NetworkX degree/clustering plus logistic
regression. Optional GCN probe when torch is enabled.

## Limitations

Synthetic communities; classical primary path. Not a production AML graph
platform.
