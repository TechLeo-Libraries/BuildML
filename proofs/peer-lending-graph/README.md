# peer-lending-graph

## Business purpose

Detect collusive default rings among P2P lending borrowers using graph-aware
classical features — distinct from card/payment fraud rings in
`graph-fraud-rings`.

## Data source

Synthetic / in-script license-clear borrower graph generated by `script.py`.

## Leakage controls

- Node stratified split before fit
- Classical graph features from train-visible graph view
- Test evaluation after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split`
2. `set_graph` (source/target edges)
3. `fit_graph` (classical) → `evaluate_graph`
4. Optional GCN probe when torch enabled → `save_graph_bundle`

## Metrics

See `results/results.json` (accuracy / f1 / roc_auc).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` uses NetworkX degree/clustering + logistic
regression (`results/comparison.json`).

## Limitations

Synthetic communities; classical primary path. Not a production AML graph
platform.
