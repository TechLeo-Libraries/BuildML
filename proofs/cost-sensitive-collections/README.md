# cost-sensitive-collections

You have a fitted scorer and FP/FN costs plus a capacity constraint. You
want a contact / collection threshold (and optional knapsack) selected on
validation, then confirmed on test.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Classical fit on train. `session.decision.fit` (threshold / knapsack) runs
on validation only. `session.decision.evaluate` on test runs after lock.

## How to run

```bash
python proofs/cost-sensitive-collections/script.py
python proofs/cost-sensitive-collections/baseline_industry.py
```

## What you'll get

`results/results.json` with cost-sensitive test metrics.
`results/comparison.json` is sklearn logistic plus a validation-only cost
threshold sweep, confirmed on test.

## Limitations

Synthetic costs; not a full OR solver suite.
