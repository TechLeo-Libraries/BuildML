# defect-active-budget

## Business purpose

Maximize manufacturing defect detection quality under a fixed inspector labeling
budget using margin-based active learning.

## Data source

Synthetic / in-script license-clear surface / vision / acoustic features
generated by `script.py`.

## Leakage controls

- Stratified split before pool masking
- Queries from train unlabeled pool only
- Test evaluated after the budget loop completes

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. Blank most train labels; keep oracle truth offline
3. `fit_active_learner` → `suggest_query` / `label_rows` loop
4. `evaluate_active_learning` → `save_active_learning_bundle`

## Metrics

See `results/results.json` (test accuracy / f1 and label curve).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` runs margin-sampling logistic active learning
on the same split (`results/comparison.json`).

## Limitations

Simulated inspector oracle; not a real defect annotation UI.
