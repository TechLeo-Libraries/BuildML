# defect-active-budget

You have manufacturing surface / vision / acoustic features and a defect
label, but inspectors are scarce. You want margin-based active learning on
the train pool, then one test check after the budget is spent.

## Data

Synthetic / in-script license-clear surface / vision / acoustic features
generated by `script.py`.

## Leakage

Stratified split before pool masking. Queries come from the train unlabeled
pool only. Oracle truth for queried train indices stays offline. Test
`session.active_learning.evaluate` runs after the budget loop completes.

## How to run

```bash
python proofs/defect-active-budget/script.py
python proofs/defect-active-budget/baseline_industry.py
```

## What you'll get

`results/results.json` with test accuracy / f1 and a label curve.
`results/comparison.json` is margin-sampling logistic active learning on the
same split.

## Limitations

Simulated inspector oracle; not a real defect annotation UI.
