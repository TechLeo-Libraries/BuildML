# active-labeling-budget

You have a limited labeling budget and a train pool with most labels blank.
You want uncertainty sampling (margin) on that pool, then one test eval
after the budget loop.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before the pool is masked. Queries come from the train unlabeled pool
only. The simulated oracle never sees validation or test. Test
`session.active_learning.evaluate` runs after the budget loop completes.

## How to run

```bash
python proofs/active-labeling-budget/script.py
python proofs/active-labeling-budget/baseline_industry.py
```

## What you'll get

`results/results.json` with test metrics and a label-budget curve.
`results/comparison.json` is margin-sampling with sklearn
LogisticRegression on the train pool only.

## Limitations

Simulated oracle labels are for the proof only.
