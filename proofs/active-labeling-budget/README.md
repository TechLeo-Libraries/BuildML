# active-labeling-budget

## Business purpose
Stretch a limited labeling budget with uncertainty sampling before final test eval.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → mask train labels
2. fit_active_learner → suggest_query/label_rows loop
3. evaluate_active_learning(test)
4. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Filled: `baseline_industry.py` runs margin-sampling with sklearn LogisticRegression on the train pool only (`results/comparison.json`).
## Limitations
Simulated oracle labels are for the proof only.
