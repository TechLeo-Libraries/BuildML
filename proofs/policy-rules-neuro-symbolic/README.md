# policy-rules-neuro-symbolic

You have tabular compliance features and a decision label. You want
interpretable rules from `session.symbolic.fit`, with an optional
neuro-symbolic overlay when torch is healthy.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before fit. Symbolic / neuro-symbolic fit on train only. Test
`session.symbolic.evaluate` after lock.

## How to run

```bash
python proofs/policy-rules-neuro-symbolic/script.py
python proofs/policy-rules-neuro-symbolic/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy and related metrics.
`results/comparison.json` is sklearn `DecisionTreeClassifier` on the same
stratified split. Optional `session.symbolic.fit_neuro` when torch is
healthy.

## Limitations

Synthetic compliance labels; rule fidelity is not legal certification.
