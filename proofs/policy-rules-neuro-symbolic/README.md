# policy-rules-neuro-symbolic

## Business purpose
Learn interpretable compliance rules and optional neuro-symbolic overlay for decisions.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split
2. fit_symbolic → evaluate_symbolic
3. optional fit_neuro_symbolic if torch healthy
4. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled: `baseline_industry.py` writes `results/comparison.json` (sklearn DecisionTreeClassifier twin on the same stratified split).


## Limitations
Synthetic compliance labels; rule fidelity ≠ legal certification.
