# causal-treatment-effect

You have a treatment, an outcome, and covariates. You want an average
treatment effect under assumptions you declare (AIPW), plus a refute, not
an EDA plot that pretends to be causal.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before fit. `session.causal.declare_assumptions` runs before
`session.causal.fit`. Nuisance models learn from train. Holdout
`session.causal.evaluate` / `session.causal.refute` after lock.

## How to run

```bash
python proofs/causal-treatment-effect/script.py
python proofs/causal-treatment-effect/baseline_industry.py
```

## What you'll get

`results/results.json` with holdout ATE plus nuisance metrics
(`outcome_rmse` / `outcome_mae` / propensity AUC) and bundle roundtrip
fields. `results/comparison.json` is AIPW with sklearn nuisance models plus
a placebo refute on the same split.

## Limitations

Assumptions are caller-declared; EDA is non-causal.
