# causal-treatment-effect

## Business purpose
Estimate average treatment effect under declared backdoor assumptions (AIPW).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → session.causal.declare_assumptions
2. session.causal.fit → session.causal.evaluate → session.causal.refute
3. session.causal.save_bundle → load_bundle → re-evaluate

## Metrics
Holdout ATE + nuisance metrics (`outcome_rmse` / `outcome_mae` / propensity AUC);
bundle roundtrip fields in `results/results.json`.

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` estimates AIPW with sklearn nuisance models + placebo refute on the same split (`results/comparison.json`).
## Limitations
Assumptions are caller-declared; EDA is non-causal.
