# credit-tda-shape

You have applicant feature clouds and a credit-risk label. You want
persistence (TDA) descriptors plus a logistic head, as a shape path next to
classical tabular models.

## Data

Synthetic / in-script license-clear two-cloud feature table generated by
`script.py`.

## Leakage

Stratified train / validation / test before any fit. Scale, TDA vectorizer,
NN index, and head fit on train only. Holdout `session.tda.evaluate` runs
after lock. Test is never used for selection.

## How to run

```bash
python proofs/credit-tda-shape/script.py
python proofs/credit-tda-shape/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / macro_f1 on validation then test.
`results/comparison.json` is classical logistic on scaled raw features (not
TDA) on the same stratified split. Competitiveness here means the TDA head
is in the same ballpark on this synthetic draw.

## Limitations

Synthetic clouds; TDA features are shape descriptors, not FICO. Requires
`ripser` + `persim` (`pip install "ripser>=0.6" "persim>=0.3"` or editable
`pip install -e ".[tda]"`). Some editable installs may not expose the `tda`
extra until reinstalled from this repo's `pyproject.toml`.
