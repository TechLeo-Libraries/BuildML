# radiology-semi-labels

You have tabular radiology proxy patches (HU / texture / edge / asymmetry)
and a lesion-present label, but only a scarce fraction of train rows are
labeled. This is not raw pixels or a CNN.

## Data

Synthetic / in-script license-clear imaging-proxy features generated by
`script.py`.

## Leakage

Stratified split before masking or fit. Train-only label masking; holdouts
keep full labels for eval. Semi-supervised fit on train; test after lock.

## How to run

```bash
python proofs/radiology-semi-labels/script.py
python proofs/radiology-semi-labels/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / f1 on fully labeled holdouts.
`results/comparison.json` is sklearn `LabelPropagation` with the same
train-only masking policy.

## Limitations

Tabular imaging proxy only: not DICOM or CNN training. Masking is a proof
harness, not a PACS annotation UI.
