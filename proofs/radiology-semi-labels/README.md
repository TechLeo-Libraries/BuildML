# radiology-semi-labels

## Business purpose

Train a lesion-present classifier when only a scarce fraction of radiology
proxy patches are labeled: semi-supervised efficiency for imaging workflows
(tabular feature proxy, not raw pixels).

## Data source

Synthetic / in-script license-clear HU / texture / edge / asymmetry features
generated by `script.py`.

## Leakage controls

- Stratified split before masking or fit
- Train-only label masking; holdouts keep full labels for eval
- Semi-supervised fit on train; test after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. Mask most train `lesion_present` labels
3. `session.semisupervised.fit` → `session.semisupervised.evaluate`
4. `session.semisupervised.save_bundle`

## Metrics

See `results/results.json` (accuracy / f1 on fully labeled holdouts).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` runs sklearn `LabelPropagation` with the same
train-only masking policy (`results/comparison.json`).

## Limitations

Tabular imaging proxy only: not DICOM or CNN training. Masking is a proof
harness, not a PACS annotation UI.
