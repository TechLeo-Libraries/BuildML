# compliance-neuro-symbolic

## Business purpose

Learn interpretable escalation rules for KYC/AML wire reviews (account age,
wire amount, PEP score, jurisdiction risk), with optional neuro-symbolic probe.

## Data source

Synthetic / in-script license-clear compliance table generated by `script.py`.

## Leakage controls

- Stratified split before fit
- Symbolic / neuro-symbolic fit on train only
- Test evaluation after lock

## BuildML API steps

1. `ingest` → `set_roles` → `split`
2. `fit_symbolic` → `evaluate_symbolic`
3. Optional `fit_neuro_symbolic` when torch paths are enabled
4. `save_symbolic_bundle`

## Metrics

See `results/results.json` (accuracy and related).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` fits sklearn `DecisionTreeClassifier`
(`results/comparison.json`).

## Limitations

Not legal advice; rule fidelity ≠ compliance certification.
