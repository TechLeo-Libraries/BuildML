# compliance-neuro-symbolic

You have KYC/AML wire-review features (account age, wire amount, PEP score,
jurisdiction risk). You want interpretable escalation rules, with an
optional neuro-symbolic probe.

## Data

Synthetic / in-script license-clear compliance table generated by
`script.py`.

## Leakage

Stratified split before fit. Symbolic / neuro-symbolic fit on train only.
Test evaluation after lock.

## How to run

```bash
python proofs/compliance-neuro-symbolic/script.py
python proofs/compliance-neuro-symbolic/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy and related metrics.
`results/comparison.json` is sklearn `DecisionTreeClassifier` on the same
split. Optional `session.symbolic.fit_neuro` when torch paths are enabled.

## Limitations

Not legal advice; rule fidelity is not compliance certification.
