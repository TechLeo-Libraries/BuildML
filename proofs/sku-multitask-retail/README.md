# sku-multitask-retail

## Business purpose

Jointly predict SKU purchase (`buy`) and margin quality (`high_margin`) from
retail assortment features — multi-target underwriting for merchandising.

## Data source

Synthetic / in-script license-clear SKU feature table generated by `script.py`.

## Leakage controls

- Split before multi-output fit
- Train-only fitting; holdout evaluation after lock

## BuildML API steps

1. `ingest` → `set_roles` (two targets) → `split`
2. `fit_multitask` (multioutput)
3. `evaluate_multitask` on validation / test
4. `save_multitask_bundle`

## Metrics

See `results/results.json` (mean accuracy / f1 across targets).

## Industry comparison (Tier C)

Filled — `baseline_industry.py` uses sklearn `MultiOutputClassifier`
(`results/comparison.json`).

## Limitations

Same-type classification targets only; not mixed regression/classification.
