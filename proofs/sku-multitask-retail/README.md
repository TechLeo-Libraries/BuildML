# sku-multitask-retail

You have retail assortment features and two classification targets: SKU
purchase (`buy`) and margin quality (`high_margin`). You want a joint
multi-output fit, not mixed regression/classification.

## Data

Synthetic / in-script license-clear SKU feature table generated by
`script.py`.

## Leakage

Split before multi-output fit. Train-only fitting; holdout evaluation after
lock.

## How to run

```bash
python proofs/sku-multitask-retail/script.py
python proofs/sku-multitask-retail/baseline_industry.py
```

## What you'll get

`results/results.json` with mean accuracy / f1 across targets.
`results/comparison.json` is sklearn `MultiOutputClassifier` on the same
split.

## Limitations

Same-type classification targets only; not mixed regression/classification.
