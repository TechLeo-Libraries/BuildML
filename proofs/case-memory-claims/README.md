# case-memory-claims

You have historical claims and a new case. You want similar past cases from
`session.cbr` to support an adjuster decision. This is case memory, not RAG.

## Data

Synthetic / in-script license-clear claims table generated by `script.py`.

## Leakage

Split before `session.cbr.fit`. Case memory is built from train only.
`session.cbr.retrieve` / `session.cbr.evaluate` on test run after lock.

## How to run

```bash
python proofs/case-memory-claims/script.py
python proofs/case-memory-claims/baseline_industry.py
```

## What you'll get

`results/results.json` with retrieval / classification metrics.
`results/comparison.json` is sklearn `KNeighborsClassifier` (distance-weighted)
on the same split.

## Limitations

Synthetic claims; CBR is not RAG.
