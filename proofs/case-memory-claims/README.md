# case-memory-claims

## Business purpose
Retrieve similar historical claims/cases to support adjuster decisions (CBR).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest cases → split
2. fit_cbr → retrieve_cases / evaluate_cbr
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled: `baseline_industry.py` writes `results/comparison.json` (sklearn KNeighborsClassifier distance-weighted twin).


## Limitations
Synthetic claims; CBR ≠ RAG.
