# coldstart-meta-adapt

## Business purpose

Few-shot repurchase prediction for cold-start product categories using
meta-learning: distinct from the domain-task episodes in
`few-shot-domain-adapt`.

## Data source

Synthetic / in-script license-clear category embedding table generated by
`script.py`.

## Leakage controls

- `group_split` by `category_id` so held-out categories never train
- Episodic evaluation on held-out categories only

## BuildML API steps

1. `ingest` → `set_roles` → `group_split`
2. `session.metalearning.fit` (prototypical, warm_start fallback)
3. `session.metalearning.evaluate` on test
4. `session.metalearning.save_bundle`

## Metrics

See `results/results.json` (episodic accuracy / f1).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` runs per-category NearestCentroid k-shot
(`results/comparison.json`).

## Limitations

Synthetic categories; not production catalog cold-start.
