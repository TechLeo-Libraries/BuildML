# coldstart-meta-adapt

You have product categories and few-shot repurchase labels. You want
meta-learning for cold-start categories: distinct from the domain-task
episodes in `few-shot-domain-adapt`.

## Data

Synthetic / in-script license-clear category embedding table generated by
`script.py`.

## Leakage

`group_split` by `category_id` so held-out categories never train. Episodic
evaluation is on held-out categories only.

## How to run

```bash
python proofs/coldstart-meta-adapt/script.py
python proofs/coldstart-meta-adapt/baseline_industry.py
```

## What you'll get

`results/results.json` with episodic accuracy / f1.
`results/comparison.json` is per-category NearestCentroid k-shot. The
Session path is prototypical, with a warm_start fallback.

## Limitations

Synthetic categories; not production catalog cold-start.
