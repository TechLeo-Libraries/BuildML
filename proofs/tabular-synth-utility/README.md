# tabular-synth-utility

You have a retail catalog / sales table (price, units, margin, category) and
want synthetic rows whose fidelity you can measure vs holdout. Distinct from
the demographic privacy table in `synthetic-privacy-utility`.

## Data

Synthetic / in-script license-clear retail catalog table generated by
`script.py`.

## Leakage

Split before synthesizer fit. `session.synthetic.fit` (gaussian_copula)
learns from train only. Fidelity is evaluated vs holdout test.

## How to run

```bash
python proofs/tabular-synth-utility/script.py
python proofs/tabular-synth-utility/baseline_industry.py
```

## What you'll get

`results/results.json` with KS / TV / correlation fidelity metrics.
`results/comparison.json` is independent column bootstrap from train. No DP
claims.

## Limitations

No differential privacy claims. Utility is not anonymity.
