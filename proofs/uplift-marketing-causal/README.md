# uplift-marketing-causal

## Business purpose

Estimate the average treatment effect of a marketing promo on spend under
declared causal assumptions (AIPW), with a placebo refute: distinct from the
generic backdoor DGP in `causal-treatment-effect`.

## Data source

Synthetic / in-script license-clear RFM + promo table generated by `script.py`
(true ATE ≈ 1.2).

## Leakage controls

- Assumptions declared before fit
- Nuisance models fit on train only
- Holdout evaluation disclosed; test reserved

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. `session.causal.declare_assumptions`
3. `session.causal.fit` (aipw) → `session.causal.evaluate` → `session.causal.refute`
4. `session.causal.save_bundle`

## Metrics

See `results/results.json` (ATE, CI, refute shift).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` runs sklearn AIPW-style estimation
(`results/comparison.json`).

## Limitations

Synthetic DGP; assumptions are declared not proven.
