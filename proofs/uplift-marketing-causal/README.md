# uplift-marketing-causal

You have RFM features, a promo treatment, and spend. You want the average
treatment effect of the promo under declared assumptions (AIPW), with a
placebo refute. True spend ATE is about 1.2 on this DGP. Distinct from the
generic backdoor table in `causal-treatment-effect`.

## Data

Synthetic / in-script license-clear RFM + promo table generated by
`script.py`.

## Leakage

Assumptions declared before fit. Nuisance models fit on train only. Holdout
evaluation is disclosed; test is reserved.

## How to run

```bash
python proofs/uplift-marketing-causal/script.py
python proofs/uplift-marketing-causal/baseline_industry.py
```

## What you'll get

`results/results.json` with ATE, interval, and refute shift.
`results/comparison.json` is sklearn AIPW-style estimation on the same
split.

## Limitations

Synthetic DGP; assumptions are declared, not proven.
