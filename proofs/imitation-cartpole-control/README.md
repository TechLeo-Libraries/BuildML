# imitation-cartpole-control

## Business purpose
Imitation learning (+ optional RL) for a control-style policy; skip gracefully without gym/torch.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. fit_imitation (BC) on expert table
2. optional fit_rl if gymnasium/torch available
3. evaluate + bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled: `baseline_industry.py` writes `results/comparison.json` (sklearn
LogisticRegression BC twin). Full Gymnasium RL twin is intentionally not the
Tier C target; when `gymnasium` is installed the BuildML script may still run
optional `fit_rl` REINFORCE-lite.

## Limitations
BC path is core. Gym REINFORCE needs `gymnasium` (`buildml[rl]`) and a healthy
torch import; otherwise that probe is skipped without failing the proof.
