# imitation-cartpole-control

You have expert action rows for a control-style task. You want behavioral
cloning via `session.rl.fit_imitation`, with an optional Gymnasium
REINFORCE probe when `buildml[rl]` and a healthy torch import are present.

## Data

Synthetic / in-script license-clear expert table generated by `script.py`.

## Leakage

Split before fit. BC learns from train expert rows only. Test imitation
metrics after lock. The optional gym probe is a separate env, not a holdout
leak into BC.

## How to run

```bash
python proofs/imitation-cartpole-control/script.py
python proofs/imitation-cartpole-control/baseline_industry.py
```

## What you'll get

`results/results.json` with imitation metrics (and optional gym probe
fields). `results/comparison.json` is a sklearn `LogisticRegression` BC
twin. A full Gymnasium RL twin is not the comparison target; when
`gymnasium` is installed the Session script may still run optional
`session.rl.fit` REINFORCE-lite.

## Limitations

BC path is core. Gym REINFORCE needs `gymnasium` (`buildml[rl]`) and a
healthy torch import; otherwise that probe is skipped without failing the
proof.
