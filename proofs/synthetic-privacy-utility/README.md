# synthetic-privacy-utility

You have a real train table and want synthetic rows plus fidelity / TSTR
utility against the holdout. This proof makes no differential privacy claim.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before `session.synthetic.fit`. The synthesizer learns from train
only. `session.synthetic.sample` / `session.synthetic.evaluate` compare
against the real holdout.

## How to run

```bash
python proofs/synthetic-privacy-utility/script.py
python proofs/synthetic-privacy-utility/baseline_industry.py
```

## What you'll get

`results/results.json` with fidelity / TSTR utility metrics.
`results/comparison.json` is an independent column bootstrap twin. No DP
claims on either path.

## Limitations

No differential privacy claims.
