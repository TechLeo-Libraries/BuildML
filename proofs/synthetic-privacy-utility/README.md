# synthetic-privacy-utility

## Business purpose
Generate synthetic tabular data and measure fidelity / TSTR utility (no DP claims).

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split
2. fit_synthesizer on train
3. sample_synthetic → evaluate_synthetic
4. bundle
