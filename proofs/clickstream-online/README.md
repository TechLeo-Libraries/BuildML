# clickstream-online

You have streaming clickstream features (pages, dwell, cart adds) and a
binary conversion label. You want online SGD with a train cursor: not batch
fraud streaming.

## Data

Synthetic / in-script license-clear clickstream table generated by
`script.py`.

## Leakage

Stratified split before online fit. `partial_fit` consumes the train cursor
only. Validation and test never enter online updates.

## How to run

```bash
python proofs/clickstream-online/script.py
python proofs/clickstream-online/baseline_industry.py
```

## What you'll get

`results/results.json` with accuracy / f1 / roc_auc.
`results/comparison.json` is sklearn `SGDClassifier.partial_fit` on the same
split.

## Limitations

Batch chunks simulate a stream; not Kafka/Flink.
