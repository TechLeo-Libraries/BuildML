# clickstream-online

## Business purpose

Score binary conversion from streaming clickstream features (pages, dwell,
cart adds) using online SGD with a train cursor: not batch fraud streaming.

## Data source

Synthetic / in-script license-clear clickstream table generated by `script.py`.

## Leakage controls

- Stratified split before online fit
- `partial_fit` consumes train cursor only
- Validation / test never enter online updates

## BuildML API steps

1. `ingest` → `set_roles` → `split` → `scale`
2. `session.online.fit` (sgd_classifier)
3. `session.online.partial_fit` until train cursor exhausted
4. `session.online.evaluate` on validation / test → `session.online.save_bundle`

## Metrics

See `results/results.json` (accuracy / f1 / roc_auc).

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` runs sklearn `SGDClassifier.partial_fit` on the
same split (`results/comparison.json`).

## Limitations

Batch chunks simulate a stream; not Kafka/Flink.
