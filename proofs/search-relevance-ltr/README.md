# search-relevance-ltr

## Business purpose
Rank documents for search queries from graded relevance judgments.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → roles → group_split(query)
2. fit_ranker (lambdarank if LightGBM else pointwise)
3. rank / evaluate_ranker
4. save_ranker_bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Filled: `baseline_industry.py` fits pointwise Ridge on the same `group_split` and reports query-averaged nDCG@5 (`results/comparison.json`).
## Limitations
Synthetic judgments.
