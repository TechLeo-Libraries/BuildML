# prob-interval-risk

## Business purpose
Produce probabilistic predictions and conformal intervals for risk scores.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → session.probabilistic.fit
2. session.probabilistic.predict_interval / session.probabilistic.evaluate
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` fits BayesianRidge and calibrates a residual quantile interval on validation only (`results/comparison.json`).
## Limitations
Coverage claims are empirical on holdout under exchangeability assumptions.
