# prob-interval-risk

You have a continuous risk score and want probabilistic predictions plus
conformal intervals you can check on a holdout.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before fit. The probabilistic model learns from train only. Selection
does not use test. Holdout `session.probabilistic.evaluate` runs after the
model is locked.

## How to run

```bash
python proofs/prob-interval-risk/script.py
python proofs/prob-interval-risk/baseline_industry.py
```

## What you'll get

`results/results.json` with interval coverage / width and related
probabilistic metrics. `results/comparison.json` is BayesianRidge with a
residual quantile interval calibrated on validation only.

## Limitations

Coverage claims are empirical on holdout under exchangeability assumptions.
