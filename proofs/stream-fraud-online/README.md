# stream-fraud-online

## Business purpose
Update a fraud classifier online from arriving labeled stream chunks.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → scale
2. fit_online → partial_fit_online loop
3. evaluate_online
4. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Filled: `baseline_industry.py` mirrors train-cursor `SGDClassifier.partial_fit` chunks (`results/comparison.json`).
## Limitations
Chunked Session updates: not a distributed streaming platform.
