# stream-fraud-online

You have arriving labeled fraud chunks. You want an online classifier
updated with `partial_fit` from a train cursor, never from test.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before scale or online fit. `session.online.partial_fit` consumes the
train cursor only. Validation and test never enter online updates. Test
`session.online.evaluate` runs after the cursor is exhausted.

## How to run

```bash
python proofs/stream-fraud-online/script.py
python proofs/stream-fraud-online/baseline_industry.py
```

## What you'll get

`results/results.json` with holdout classification metrics.
`results/comparison.json` mirrors train-cursor `SGDClassifier.partial_fit`
chunks on the same split.

## Limitations

Chunked Session updates: not a distributed streaming platform.
