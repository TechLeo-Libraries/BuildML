# ssl-representation-probe

You have a table with scarce labels. You want a masked-tabular pretext on
train features, then a linear probe, then one holdout number.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Split before pretext. `session.ssl.fit_pretext` and the probe head learn
from train only. Test `session.ssl.evaluate` runs after lock.

## How to run

```bash
python proofs/ssl-representation-probe/script.py
python proofs/ssl-representation-probe/baseline_industry.py
```

## What you'll get

`results/results.json` with probe classification metrics.
`results/comparison.json` is label-free PCA pretext plus a logistic probe
on the same split.

## Limitations

Tabular masked pretext; not ImageNet SSL.
