# ssl-representation-probe

## Business purpose
Learn tabular representations via pretext then train a linear probe on scarce labels.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → split → session.ssl.fit_pretext
2. session.ssl.finetune_head / session.ssl.evaluate
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)

Industry twin: `baseline_industry.py` uses label-free PCA pretext + logistic probe on the same split (`results/comparison.json`).
## Limitations
Tabular masked pretext; not ImageNet SSL SOTA.
