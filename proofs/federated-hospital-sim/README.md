# federated-hospital-sim

## Business purpose
Simulate multi-hospital FedAvg without centralizing raw rows; disclose simulation honesty.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → assign client groups → session.federated.fit
2. session.federated.evaluate (accuracy / f1_macro / balanced_accuracy / roc_auc)
3. session.federated.save_bundle → load_bundle → re-evaluate

## Metrics
Holdout classification metrics + per-client slices; bundle roundtrip and Flower
local-sim honesty flags in `results/results.json`.

## Industry comparison (Tier C)
Industry twin: `baseline_industry.py` writes `results/comparison.json` (pooled centralized SGD contrast on the same group_split).


## Limitations
Local simulation: not Flower production federation. Optional Flower backend is
also disclosed as in-process local-sim (`network_runtime=false`).
