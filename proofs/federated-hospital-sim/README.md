# federated-hospital-sim

You want a multi-hospital FedAvg loop that does not centralize raw rows, and
an honest disclosure that this is a local simulation.

## Data

Synthetic / in-script license-clear table generated by `script.py`.

## Leakage

Client groups are assigned before `session.federated.fit`. Federated updates
use train clients only. Holdout evaluation is after lock. Test is never used
for selection.

## How to run

```bash
python proofs/federated-hospital-sim/script.py
python proofs/federated-hospital-sim/baseline_industry.py
```

## What you'll get

`results/results.json` with holdout accuracy / f1_macro / balanced_accuracy /
roc_auc, per-client slices, bundle roundtrip fields, and Flower local-sim
honesty flags. `results/comparison.json` is pooled centralized SGD on the
same `group_split`.

## Limitations

Local simulation: not Flower production federation. Optional Flower backend
is also disclosed as in-process local-sim (`network_runtime=false`).
