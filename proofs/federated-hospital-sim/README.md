# federated-hospital-sim

## Business purpose
Simulate multi-hospital FedAvg without centralizing raw rows; disclose simulation honesty.

## Data source
Synthetic / in-script license-clear data generated by `script.py`.

## Leakage controls
- Proper split before fit (random / group / time as domain requires)
- Train-only fitting and selection
- Holdout evaluation after model lock
- Test never used for selection

## BuildML API steps
1. ingest → assign client groups → fit_federated
2. evaluate_federated
3. bundle

## Metrics
See `results/results.json` after a successful run.

## Industry comparison (Tier C)
Filled: `baseline_industry.py` writes `results/comparison.json` (pooled centralized SGD contrast on the same group_split).


## Limitations
Local simulation: not Flower production federation by default.
